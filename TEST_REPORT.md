## 3. Проверка Object Pascal и ISAPI DLL

Статически проверено:

- строки и комментарии закрыты;
- `begin/end`, `try/except`, `try/finally` и объявление класса сбалансированы;
- все 11 методов `TWebModule1` объявлены и реализованы с совпадающими
  параметрами и возвращаемыми типами;
- `interface`, `implementation` и `uses` согласованы;
- имена `WebModuleUnit` и `DbUnit` совпадают с именами файлов;
- циклической зависимости между units нет;
- DFM содержит `TWebModule1`, один Default action и существующий обработчик;
- все локальные `TADOConnection` и `TADOQuery` освобождаются в `finally`;
- соединение освобождается, если `Open` вызывает исключение;
- UTF-8-поток передаётся во владение `TWebResponse`, а при промежуточной
  ошибке освобождается;
- обращение к `Path[1]` безопасно и не зависит от `{$B+/-}`;
- COM инициализируется для потока запроса и симметрично освобождается только
  при `S_OK` или `S_FALSE`;
- общей изменяемой информации между запросами нет: соединение и запросы
  создаются локально;
- в пользовательском коде нет указателей, `PChar`, ручной передачи строк через
  границу DLL, `external`, `forward` и нестандартных calling convention;
- нет условных `{$IFDEF}` и маркеров незавершённой разработки.

В `.dpr` экспортируются ровно стандартные точки ISAPI:

```text
GetExtensionVersion
HttpExtensionProc
TerminateExtension
```

Их типы параметров и соглашение `stdcall` предоставляет штатный unit
`Web.Win.ISAPIApp`; собственных функций на ABI-границе DLL нет. Код обработчика
перехватывает обычные `Exception`, пишет подробность в серверный журнал и
возвращает пользователю нейтральный ответ 500.

## 4. Проверка HTTP и безопасности

Проверены:

- маршруты `/`, `/new`, `/create`, ответы 400/404/405/413;
- POST проверяется до чтения полей и INSERT;
- размер POST ограничен 16 КБ;
- список ограничен последними 200 записями;
- обязательные поля и длины проверяются на сервере;
- `department_id` преобразуется в `Integer` и проверяется по справочнику;
- INSERT параметризован, типы и размеры ADO-параметров заданы явно;
- `DATETIME2` приводится к `datetime` для совместимости с ADO, а дата выводится
  в формате `dd.mm.yyyy hh:nn`;
- пользовательские данные кодируются для HTML;
- после INSERT применяется Post/Redirect/Get (303), исключающий дубль по F5;
- ответы формируются в UTF-8;
- установлены CSP, `nosniff`, `X-Frame-Options`, `Referrer-Policy`,
  `Cache-Control` и `Allow: POST`.

## 5. Проверка SQL Server

Статически подтверждены:

- база `HelpDeskWebDB`;
- таблицы `Departments`, `RequestStatuses`, `ServiceRequests`;
- первичные, внешние и уникальные ключи;
- индексы внешних ключей;
- `NVARCHAR` для русскоязычных данных;
- три CHECK-ограничения непустых строк;
- значения по умолчанию для статуса и времени;
- демонстрационные данные;
- smoke-тест структуры, индексов, INSERT и ROLLBACK;
- отдельный тест эффективных прав IIS;
- пул получает только `SELECT` на три таблицы и `INSERT` на заявки;
- UPDATE, DELETE, CONTROL и `db_owner` не выдаются.

Для ADO добавлены `DataTypeCompatibility=80` и проверенный на локальном стенде
режим `Use Encryption for Data=Optional`. Строку подключения можно задать
переменной `HELPDESKWEB_CONNECTION_STRING`; пароль в исходниках отсутствует.

## 7. Границы автоматической и ручной проверки

Codex не запускал `bds.exe`, `dcc32.exe` и MSBuild. Ручная сборка Win32 Release
в Delphi 12, создание базы, SQL smoke-тест, загрузка DLL в IIS, чтение заявок и
создание заявки подтверждены владельцем проекта.

После финальной правки встроенной строки подключения владелец повторно выполнил
ручную сборку Win32 Release. Переменная `HELPDESKWEB_CONNECTION_STRING` удалена
из пула, приложение продолжило работать, а полный интеграционный тест завершился
без ошибок.

## 8. Результат финальной ручной проверки

1. Проект собран вручную для Windows 32-bit в конфигурации Release.
2. Предупреждение W1030 после правки `.dproj` исчезло.
3. DLL заменена в IIS; исходная и развёрнутая копии имеют одинаковый SHA-256:
   `2EBE22FC012FB81B3C2E7A99BFBB77766ED0627672FD03DC9BE4A71447E9AED0`.
4. Встроенная DLL содержит `Use Encryption for Data=Optional` и не содержит
   `Encrypt=Mandatory`.
5. Без переменной окружения главная страница возвращает HTTP 200 и отображает
   демонстрационные заявки.
6. `tests/Test-HelpDeskWeb.ps1` завершился только с результатами `PASS`.
